# BulkLab — Workout & Meal Prep

A static, mobile-friendly workout and meal prep app. No build process, dependencies, paid services, or server required.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com) and create a new **public** repository, e.g. `bulklab`.
2. Choose **Add file → Upload files** and upload **the contents of this folder** (`index.html`, `manifest.webmanifest`, and both icon PNGs). Do not upload the ZIP itself. Commit to the `main` branch.
3. Open the repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
5. Once GitHub publishes it, visit `https://YOUR-USERNAME.github.io/bulklab/` in **Safari** on your iPhone. (Your exact link depends on the repository name.)
6. In Safari, tap **Share → Add to Home Screen → Add** to install a shortcut that launches like an app.

**Do not open `index.html` in the Files app preview**; that viewer may block the app's JavaScript. Open the HTTPS GitHub Pages URL in Safari instead.

## Privacy and backups

- The app stores workouts, weigh-ins, and meal plans in your browser's local storage on the current device. GitHub does **not** receive or sync your logs.
- Use **Backup data** to export a JSON backup regularly. Use **Restore** to load it into another browser or device.
- Existing data saved under the `bulklab-v1` key in a different file origin may not transfer automatically. Export from the old version first.
- Clearing website data, using private browsing, or changing devices can erase local data.
- YouTube form demonstration links require an internet connection.

## Edit and republish

Replace `index.html` in your GitHub repository and commit; GitHub Pages will update the hosted site. Keep the backup JSON file private.

## Included

Beginner and four-day strength programs, per-set logging, body-weight chart, 15 banana-free/pork-free meal recipes, serving-based grocery planner, and JSON backup/restore.
