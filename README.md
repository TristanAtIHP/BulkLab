# BulkLab — GitHub Pages update

Replace the existing repository files with the files in this folder. Keep `index.html` at repository root. GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)`. On iPhone, reload Safari or close and reopen the Home Screen app after GitHub deploys.

## What changed
- Live completed-set progress bar in Workouts and Dashboard, scoped to selected date and session.
- Dashboard buttons use delegated navigation.
- Expanded meal catalog, with no pork, shellfish, banana or soy-based sauces. Soy-free sauce substitution is used. Recipes have more detailed instructions.
- Same `bulklab-v1` localStorage key to retain existing workout and weigh-in data on the same site and browser.

## Data safety
Use Backup data before replacing files. GitHub Pages hosts the app but does not synchronize workout data between devices.
